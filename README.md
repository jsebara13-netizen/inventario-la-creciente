# Sistema de información para el control de inventarios de la Tienda La Creciente

Proyecto académico del **Instituto Tecnológico Metropolitano (ITM)**, programa de Tecnología en Diseño y Programación de Soluciones de Software como Servicio (SaaS). Corresponde a la actividad del foro de la Unidad 2.

## Problema

La Tienda La Creciente es una miscelánea de barrio con muchas referencias y muchas ventas de bajo valor. Ya cuenta con un software de ventas, pero el módulo de inventario no se usa: solo se controlan las ventas. Esto genera:

- Pérdidas por productos vencidos
- Desabastecimiento de artículos de alta rotación
- Exceso de mercancía de baja rotación

## Objetivo

Diseñar e implementar un sistema de información que permita conocer las existencias reales de los productos, optimizar el proceso de compras y reducir las pérdidas por vencimiento o desabastecimiento, sin disminuir la eficiencia de la tienda.

## Alcance

- Carga inicial masiva del inventario (Excel o CSV)
- Registro de recepción de mercancía con cantidad, costo y vencimiento
- Descuento automático de stock por cada venta
- Consulta de existencias en tiempo real
- Alertas de bajo stock y de productos próximos a vencer
- Conteo físico y ajustes de inventario
- Reporte de rotación y lista sugerida de compras
- Usuarios con permisos (dueño y vendedor)
- Historial de movimientos por producto

## Gestión del proyecto

Las 10 historias de usuario (52 puntos de historia) se gestionan como *issues* y se organizan en el tablero de la pestaña **Projects** de este repositorio.
